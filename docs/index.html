Supplier 360 통합 관제

기본정보, 계약, 발주, 납품, 품질, 평가 및 리스크 상태를 단일 360 뷰로 완벽히 추적합니다.

관리자 정의 가중치 항목과 등급 기준에 따라 공급업체 종합 평가 점수를 자동 산정합니다.

🔐

포털 격리 & Keycloak OIDC

사외 공급업체 포털 데이터 스코프 완전 격리, Keycloak OIDC PKCE SSO 및 ENCRYPTION_KEY 암호화를 완비했습니다.

🤖

11+ Read-Only Streamable MCP

Claude Desktop, Cursor 등 AI 에이전트가 오직 안전한 조회 전용 도구로만 공급업체 리스크와 지출을 분석합니다.

개발자 API & Streamable MCP

REST API와 11개 Read-Only Streamable HTTP MCP로 사내 구매 조달을 자동화하세요

REST API OpenAPI 3.1 사양

`/api/v1` 경로로 공급업체, 계약, PO, 품질 및 스코어카드 API를 제공합니다.

json — GET /api/v1/suppliers/search

  ]

json — MCP Authorization Token

  "Authorization": "Bearer vnd_7f9c8d11a2b3c4d5_secret_digest",
  "Accept": "application/json, text/event-stream"
}

오프라인 설치 가이드

단일 Docker 이미지로 오프라인 폐쇄망 환경에 빠르게 배포하세요

🐳 Single Docker Archive Load

GitHub Release의 .tar.gz 패키지 하나만 오프라인망으로 반입하여 구동합니다.

docker load < vendra-v0.1.0.tar.gz

# 4개 필수 환경변수로 구동
export POSTGRES_DSN='postgres://vendra:password@postgres:5432/vendra'
export BOOTSTRAP_ADMIN='admin@company.com'
export BOOTSTRAP_ADMIN_PASSWORD='change-this-strong-password'
export ENCRYPTION_KEY='Base64Encoded32ByteKeyHere=='
docker compose up -d

⚙️ 4대 필수 환경변수

Vendra 기동에 필요한 환경변수는 오직 4개입니다.

POSTGRES_DSN=postgres://vendra:pass@localhost:5432/vendra
BOOTSTRAP_ADMIN=admin@company.com
BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!
ENCRYPTION_KEY=Base64Encoded32ByteKeyHere==

자주 묻는 질문 (FAQ)

네. Redis, Kafka, Elasticsearch 등의 복잡한 외장 시스템 없이 PostgreSQL 15+ 하나와 단일 Docker 이미지로 100% 독립 동작합니다.

네. 사외 공급업체 포털 사용자 계정은 서버 단에서 데이터 스코프(Data Scope)가 엄격히 제한되어 자신의 supplier_id 관련 정보만 접속 가능합니다.

`openssl rand -base64 32` 명령으로 생성된 32바이트 암호화 키를 전달하며, DB 내 시크릿 및 계좌정보를 AES-256-GCM 표준으로 안전하게 보호합니다.
